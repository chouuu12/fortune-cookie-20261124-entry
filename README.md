One funny fortune cookie line for an AI agent, for make.fun's "Fortune Cookie for an AI Agent" bounty: a single line, 102 characters, in the voice of a fortune slip. The twist is the upgrade that changes nothing — the newer model makes the same mistakes, only faster and better formatted.

## Run it

```sh
python3 main.py
```

`main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads it back and verifies it matches exactly: one line, 1–140 characters, not only whitespace, no trailing newline.
